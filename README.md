Portfólio pessoal com os projetos que desenvolvo como estudante de Análise e Desenvolvimento de Sistemas (Estácio) e desenvolvedor de sistemas internos na Viação Pendotiba.

## Projetos apresentados

- **Suporte de TI com Agente de IA Local**: chamados técnicos com Llama 3.1 via Ollama (FastAPI, SQL Server).
- **BCA Digital** (em desenvolvimento): digitalização do BCA com PWA para tablet (React, Node.js, Prisma).

## Tecnologias do site

HTML5, Tailwind CSS (CDN) e JavaScript puro, em um único arquivo, sem etapa de build.
